# Data provenance and redistribution

The starting records were curated from the Lipid Nanoparticle Database (LNPDB), a publicly accessible and downloadable LNP structure–function database described by Collins et al. (2026). The public LNPDB repository containing the database is distributed under a repository-level MIT License. A copy of the license as provided by the LNPDB repository is included in this package as LNPDB_MIT_LICENSE.txt. The associated Nature Communications article is distributed under the Creative Commons Attribution 4.0 International License (CC BY 4.0).

The data deposited here represent the project-specific snapshot used in the present study rather than the current live version of LNPDB. The starting records underwent study-specific curation, harmonization, activity labeling, partitioning, and feature generation as described in the manuscript, Supporting Information, and accompanying pseudocode. Users reusing these data should cite both the original LNPDB publication and the present study.

LNPDB reference: Collins, E., Ji, J., Kim, S.-G. et al. Lipid Nanoparticle Database towards structure-function modeling and data-driven design for nucleic acid delivery. Nature Communications 17, 2464 (2026). https://doi.org/10.1038/s41467-026-68818-1
