# Proprietary implementation and reviewer executable

The original analysis implementation is not included in the public package because the project source code is subject to third-party proprietary restrictions associated with industry-funded work. The public `10_Pseudocode/` directory provides the implementation-independent computational specification, while the deposited data, frozen analysis states, decision-driving outputs, manifests and checksums allow direct audit of the published workflow.

Executable access for editors and referees is handled separately from this public archive through the journal-approved confidential review process. That reviewer/editor executable package is not part of the persistent public reproducibility deposit and does not alter the contents, hashes, or scientific scope of this archive.

No public file should be interpreted as a source-code release.
