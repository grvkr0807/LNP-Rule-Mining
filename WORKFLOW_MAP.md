# End-to-end workflow map

1. **Curate and preprocess LNPDB records.** Begin from the 17,116-record curated snapshot; separate in vitro and in vivo records; standardize constituent structures, categorical fields, and missing-data handling.
2. **Assign source-relative activity labels.** Fit source-wise one-dimensional k-means (k=2; random state 42), define standard labels, generate HC10/HC20 boundary-exclusion variants without refitting, and retain Top10/Top20 as diagnostics only.
3. **Freeze source-disjoint in vitro partitions.** Assign complete sources to hyperparameter-selection, development, and independent-validation partitions; reuse the frozen source assignment for HC10/HC20.
4. **Featurize and quality-control.** Construct the 881-feature representation, learn the molecular-constant QC mask on standard-k-means development data only, and apply the resulting 420-feature mask to all label/split combinations.
5. **Characterize redundancy and chemistry.** Evaluate joint Pearson/Spearman correlation clusters; retain strict complete-linkage at 0.99 for Phase-1 rescue. Evaluate Bemis-Murcko scaffolds and Morgan/Butina fingerprint clustering; lock Tanimoto similarity 0.70 for chemistry-aware grouped CV.
6. **Tune and benchmark models.** Tune seven classifiers on the dedicated hyperparameter partition; benchmark on common development folds; retain LightGBM as primary and class-weighted RF as model-family sensitivity.
7. **Run 12-branch pre-refinement robustness analysis.** Cross three label definitions, two CV strategies, and two model families; choose five complementary refinement cases.
8. **Phase 1 coarse refinement.** Iterate held-out-fold SHAP main effects, interaction-partner rescue, and correlation-cluster rescue for 25 iterations; retune after iterations 5/10/15/20; Pareto-screen and use repeated-CV uncertainty to select Phase-2 handoffs.
9. **Phase 2 fine refinement.** Map retained features to the fixed 12-class taxonomy; exhaustively evaluate all nonempty represented class combinations with frozen folds/hyperparameters; re-evaluate only the numerical best with 10x5 CV; use its SE to define the threshold and select the smallest qualifying combination.
10. **Phase 3 finest refinement.** Retune the exact Phase-2 handoff, compute global held-out-fold TreeSHAP main-effect rankings, lock Top-18 pools for Cases 1/2/3/5 and all 12 features for Case 4, retune, exhaustively evaluate every nonempty individual-feature subset, and select using the same numerical-best/SE threshold principle.
11. **Phase 4 rule mining.** Quantile-bin continuous features, preserve binary categorical states, enumerate conjunction rules, filter by support/precision/Wilson lower bound, rank using conservative complexity-penalized utility, and prune exact-coverage and non-improving supersets. Lock bins=6, support=50, precision=0.65, lambda=0.5, maximum order=4 from one-factor-at-a-time sensitivity.
12. **Independent in vitro validation.** Freeze all Case-1 rules and rankings; apply unchanged to the source-disjoint validation matrix; report source-adjusted enrichment by frozen rank windows.
13. **Retrospective in vivo transferability.** Reuse the in vitro LightGBM parameters, transfer Phase-1/2/3 feature identities by exact name, compare to unrestricted in vivo baselines, and apply the frozen Case-1 rulebook unchanged with source-adjusted enrichment.
